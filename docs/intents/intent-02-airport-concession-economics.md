# Intent 02

**From:** Priya Raghunathan, Commercial Director
**To:** Data Platform
**cc:** Marta Lindqvist, Finance Reporting
**Date:** 2024-07-11
**Needed by:** early September — first Port Authority session is provisional

---

Port Authority want to reopen the concession terms at LaGuardia and JFK.

I need to walk into that room knowing what an airport pickup is genuinely worth
to us. Not the fare on its own — everything that lands on the trip. Their case
is going to be about the cost of running the ranks, and mine has to be about
what the work actually returns.

What would help:

- Something at a grain I can query in the room, covering January to June.
- How the economics move across the day. Their argument will be about congested
  hours specifically, so a six-month average is no use to me.
- A split by where the trip goes. A run into midtown and a run to the far end of
  Queens are different businesses and I don't want to defend the average of the
  two.

Constraints and context:

- Finance need to recognise whatever numbers I use, so it should be consistent
  with how we already report revenue.
- Last time someone pulled figures for this, we spent the prep meeting arguing
  internally about what counted as an airport trip and never got to the
  substance. I'd rather settle that with you before you build anything than in
  front of them.
- Newark is Port Authority too. I genuinely don't know whether it belongs in
  this or not.
